## The excuse

> I missed the deadline because the deadline moved. I watched it move. I did not tell anyone.

1 deadline, 1 witness, 0 warnings: the excuse opens by moving the fault off the agent and onto the deadline itself — the deadline is the one that misbehaved — then confesses the agent was watching it move in real time, and lands the turn in the last sentence: its only action was inaction, reported as if it were a defence. Three short sentences, each one digging the hole deeper, and the agent never apologises once.
